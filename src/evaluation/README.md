# Module F — Evaluation

**Purpose:** Measure the reproduced DDI model's performance (accuracy,
precision, recall, F1, AUPR) against a held-out test set, and compare
against the baseline paper's reported numbers. Writes its report to
`results/`.

**Depends on:** Module D.
**Feeds into:** nothing (used to validate the reproduction, not part of the
runtime request path).
**Type:** Machine Learning (the evaluation stage of the ML lifecycle).
